# Лабораторная работа 6. Списки и обработка наборов данных

## Как запустить
`python statistics.py`, `python transform.py`, `python positions.py`, `python variant.py`.

---

## Таблица проверок

### 1. `statistics.py`
| Ввод | Ожидаемый результат | Фактический |
|---|---|---|
| `-2 0 5 3` | Кол-во 4, сумма 6, мин -2, макс 5, среднее 1.50 | Совпадает |
| `8` | Кол-во 1, сумма 8, мин 8, макс 8, среднее 8.00 | Совпадает |
| пустая строка | Нет данных | Совпадает |

### 2. `transform.py`
| Ввод | Ожидаемый исходный | Ожидаемый новый |
|---|---|---|
| `-2 0 5 -2` | `[-2, 0, 5, -2]` | `[2, 0, 5, 2]` |
| пустая строка | `[]` | `[]` |

**Исходный список сохраняется** — мы не изменяем его, а создаём `new_numbers`.

### 3. `positions.py`
| Ввод | Ожидаемый результат |
|---|---|
| `7 7` | `[0, 1]` |
| `-3 -1 -2` | `[1]` |
| `3 7 2 7` | `[1, 3]` |
| пустая строка | Нет данных |

### 4. `variant.py` (Вариант 1 — чётные числа)
| Ввод | Ожидаемый результат |
|---|---|
| `-8 -3 0 6 6 1` | Выборка `[-8, 0, 6, 6]`, кол-во 4, сумма 4, сортированная `[-8, 0, 6, 6]` |
| `1 3 5` | Выборка `[]`, кол-во 0, сумма 0, сортированная `[]` |
| пустая строка | `[]`, 0, 0, `[]` |

**Непустой пример для варианта 1:** `2 4 7 10` → выборка `[2, 4, 10]`, кол-во 3, сумма 16.

### 5. `unique.py` (дополнительно)
| Ввод | Ожидаемый результат |
|---|---|
| `3 1 3 2 1` | `[3, 1, 2]` |
| пустая строка | `[]` |
